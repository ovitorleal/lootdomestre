# Loot do Mestre

Gerador de tesouros para mestres de D&D 5.5e / 2024, baseado no SRD 5.2.1.

## Executar localmente

Abra `index.html` em um navegador. O app é estático e não precisa de build nem dependências.

## Publicar no Vercel

Importe este repositório no Vercel, selecione o framework **Other** e mantenha a raiz do projeto como diretório de saída. O `index.html` será servido automaticamente.

As tabelas de tesouro e faixas de moedas do gerador são parâmetros narrativos simplificados próprios, não tabelas oficiais do SRD.
