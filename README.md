# Loot do Mestre

Gerador de tesouros para mestres de D&D 5.5e / 2024, baseado no SRD 5.2.1. O catálogo inclui as 253 entradas da lista oficial de itens mágicos, com raridade e referência direta. O histórico local evita repetir itens recentes enquanto houver opções inéditas na faixa.

## Executar localmente

Abra `index.html` em um navegador. O app é estático e não precisa de build nem dependências.

## Publicar no Vercel

Importe este repositório no Vercel, selecione o framework **Other** e mantenha a raiz do projeto como diretório de saída. O `index.html` será servido automaticamente.

As faixas de tesouro e as probabilidades de saque são parâmetros narrativos próprios; o SRD não publica tabelas oficiais de loot por ND.
